# CampusConnect   
*A Smart Web Portal for Student–Faculty Interaction & Campus Navigation*

CampusConnect is a full-stack web application designed to streamline communication between students and faculty while simplifying campus navigation and academic coordination.  
The platform centralizes faculty search, availability tracking, appointments, events, and notifications into a single, secure system.

This project was built with scalability, modularity, and real-world campus workflows in mind.

---

##  Key Features

###  Authentication & Security
- Secure login & registration
- Role-based access (Student / Faculty / Admin)
- Password reset with OTP support
- Protected routes and API endpoints

###  Faculty & Department Search
- Search faculty by name or department
- View faculty details (designation, cabin, timetable)
- Real-time availability status

###  Appointments & Notifications
- Book appointments with faculty
- Event & appointment notifications
- Centralized dashboard for updates

###  Campus Navigation
- Interactive campus map
- Building and department lookup
- Easy navigation for new students

###  Dashboards
- Student dashboard: profile, events, notifications
- Faculty dashboard: availability, appointments
- Admin control for managing data
